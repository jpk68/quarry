## Quarry

Software for mining Monero on P2Pool. Highly work-in-progress.

### About

This project is an effort to make it simpler to mine Monero on P2Pool, improve client diversity, and
grow its share of the network hashrate. We aim to provide an alternative implementation of the
RandomX mining algorithm and P2Pool server, with a focus on speed and resource-efficiency.

### Status

Not much works yet, but stay tuned.

### Build from source

Building requires the latest [Zig master build](https://ziglang.org/download/).

```bash
git clone https://codeberg.org/jpk68/quarry
cd quarry
zig build
```
