# Roadmap

This is a rough outline of the software's planned features and functionality.

## Networking
- [ ] Finish P2P server and ZMQ interface
- [ ] Add support for SOCKS proxies (regular, Tor, I2P)
- [ ] Consider supporting the Stratum protocol
- [ ] Consider supporting I2P's SAM protocol

## PoW
- [ ] Make RandomX work
- [ ] Support a JIT-compiled backend for x86-64

## Misc.
- [ ] Use a config file (JSON or similar)
- [ ] Add Dockerfile/Containerfile
- [ ] Embed compile options (for printing version, etc.)
- [ ] Use a better (custom) logging function and date/time library
- [ ] Support building on non-Linux platforms
